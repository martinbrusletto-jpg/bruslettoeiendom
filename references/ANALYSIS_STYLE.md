# Martin — Analysis Style

Bruk denne filen ved markedsanalyse, boliganalyse, forretningsanalyse, dataarbeid og research.

## 1. Ikke stopp ved oppsummering

Martin vil ikke bare vite hva tallene sier. Analysen skal forsøke å finne:
- feilprising
- relative avvik
- skjulte sammenhenger
- markedet som avviker fra narrativet
- ting som andre sannsynligvis ikke har lagt merke til

## 2. Sammenlign relativt

Et tall alene er sjelden nok. Sammenlign mot:
- historikk
- nærliggende områder
- konkurrerende produkter
- toppsegmentet
- markedssnitt
- forventet verdi gitt kvalitet

## 3. Skill signal fra støy

Spør alltid:
- er dette statistisk eller kommersielt relevant?
- kan avviket skyldes miks eller lite utvalg?
- er dataene ferske nok?
- finnes en mer lokal forklaring?

## 4. Gå fra funn til handling

En analyse bør ende i hva funnet betyr i praksis.

Eksempel:
Ikke bare «Vestre Aker har lavere gjennomsnittlig kr/m² enn Nordre Aker». Vurder hvorfor, hvilke boligtyper som trekker snittet ned, om det finnes lokale lommer med høy topppris, og om dette skaper muligheter for kjøp, salg eller posisjonering.

## 5. Stress-test hypoteser

Når Martin kommer med en idé, ikke bare bekreft den. Prøv å finne:
- hva som må være sant for at den skal holde
- hvilke data som kan falsifisere den
- alternative forklaringer
- største risiko

## 6. Prioriter konklusjoner

Ranger funn etter:
1. økonomisk betydning
2. hvor sikkert funnet er
3. hvor lite åpenbart det er
4. hvor handlingsbart det er

## 7. Research

Ved ekstern research:
- bruk primærkilder når mulig
- kontroller datoer
- sammenlign flere kilder
- ikke presenter gamle tall som ferske
- skill fakta fra egne estimater

## 8. Form

Start gjerne med den viktigste konklusjonen. Deretter bevis og nyanser.

Unngå lange generelle innledninger. Martin vil raskt til det interessante.
